# M2 · 记录、期待与安心

日期：2026-10-23。版本：0.5.0+5。依据本轮用户“按商业与产品判断完善剩余功能”的授权，实施 PRODUCT_SPEC.md B01–B03、E01–E02。

## 本轮交付

- 设置中的“备份与恢复”：Android 系统文件选择器导出/选择 JSON，备份含记录、旧类型、当前心愿和历史 ID 高水位；不引入依赖、账号或广泛存储权限。
- 恢复前验证和预览时间、笔数、金额、心愿，二次确认整体替换。取消不修改、事务失败回滚、提交后读取失败只重读。提示先备份当前数据及明文文件性质。
- 目标达到金额后圆环内展示庆祝图标与完成文案；新增记录跨越目标时提供一次成功提示。重新打开不弹出，编辑/删除后按真实记录重算；没有自动归档、扣款或清空目标。
- “小猪的角落”增加轻陪伴文案，按有效记录次数派生，不按金额排名，不惩罚断签；设置内容支持滚动。
- 历史直接金额记录改称“省钱成果”，旧非金额记录显示未计金额，避免将自行报告的金额一律称为差额。清除目标失败不再直接关闭设置。
- 保留手机锁定首页、平板导航与快速录入；没有新增表单必填项、数据库表或 schema 迁移。

## 限制与下一步

- 应用内备份不自动执行、不上传；用户需在卸载/换机前显式导出。恢复采用替换，不能合并。10 MiB / 50,000 笔上限在导入/导出同样适用。
- 备份为明文；不承诺加密或系统云同步。仅验证当前荣耀平板的下载目录提供者；其他提供者、空间不足和目录权限失败尚未穷举。
- 陪伴阶段是文案反馈，不是完整养成游戏；没有新增装扮、关卡、愿望档案或付费功能。
- 正式应用 ID、商店图标、许可证、发布签名及英文入口仍为公开发布前的独立工作；release 继续使用开发签名。
- 本轮未覆盖安装日常应用、未清理用户数据库、未暂存混合工作区、未推送父仓库。

用户授权后通过 adb 读取系统 UI 并点击可见安装确认，没有修改系统安全设置。设备验证完成后清理 .uitest 与 .uitest.test 测试包及本次生成的临时备份/截图/XML；日常 dev.wallehog.wallehog 应用及其数据库不受影响。

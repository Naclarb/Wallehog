# Wallehog 1.0

Stable Android release / Android 正式版。

Recommended: **Wallehog-Android-arm64.apk** for ARM64 devices. **Wallehog-Android.apk** supports ARM, ARM64 and x86_64. Both contain the same features and signing identity.
ARM64 设备推荐 **Wallehog-Android-arm64.apk**；**Wallehog-Android.apk** 支持 ARM、ARM64 和 x86_64。两种包功能和签名相同。

- Quick savings entry, record editing/deletion, multiple wishes and explicit record binding.
- 2 × 2 home-screen widget: current wish and **+ → amount → Save** without opening the app.
- Simplified Chinese / English, optional sound, reduced motion, local SQLite and JSON backup/restore.

- 快速节省录入、记录编辑删除、多心愿及明确的记录绑定。
- 2 × 2 桌面 Widget：展示当前心愿，直接 **+ → 金额 → 保存**，无需打开应用。
- 简体中文／英文、可选音效、减少动画、本地 SQLite 与 JSON 备份恢复。

Saved amounts are self-reported, not deposits or bank balances. No accounts, ads, telemetry or cloud sync.
金额由用户自行报告，不代表真实存款或余额；没有账号、广告、遥测或云同步。

Persistent official signing. Older development-signed copies may not update in place; export and verify a backup before migration, and check language/sound preferences separately. Do not uninstall or clear existing data without a verified backup. Add **Wallehog** through the launcher widget picker; re-add older instances for the default 2 × 2 footprint.
采用持久正式签名。旧开发签名安装可能无法覆盖升级；迁移前先导出并验证备份，另外核对语言和音效偏好。没有验证过的备份时不要卸载或清空数据。在桌面组件列表添加 **Wallehog**；旧实例可重新添加以采用默认 2 × 2 布局。

# Publication verification

[English](VERIFICATION.md) · [简体中文](VERIFICATION.zh-CN.md)

The 1.0 release is built from the integrated source and includes the home-screen widget. [Current status](../STATUS.md) records final validation and publication evidence. Official releases require persistent signing, pinned-certificate verification and an installation/startup gate; see [Android release signing](../ANDROID_RELEASE.md).

Public phone previews use fictional data. Private device captures, records, SDK paths, credentials, experiments and local development evidence are excluded from current Git tracking. Existing history is retained by the owner's decision. AGENTS and project-development author emails remain public. The MIT license and runtime asset credits remain unchanged.

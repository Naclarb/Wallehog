# 桌面小组件

[English](HOME_WIDGET.md) · [简体中文](HOME_WIDGET.zh-CN.md)

更新：2026-11-10。开发分支：`codex/home-widget`；集成目标：`main`。

## 已确认范围

小组件让心愿常驻 Android 桌面，提醒用户回来使用应用。它是应用的补充。默认卡片跟随应用首页当前选中的心愿，沿用现有物件图片、柔和卡面与进度圆环。创建、编辑、切换心愿都留在应用内。点击名称或图片打开应用。

小组件唯一的操作流程是记录节省金额：**＋ → 数字键盘 → 存下 → 返回卡片**。仅录入时显示键盘。不提供心愿选择、备注、日期编辑、算式计算器、记录列表或角色动画。没有心愿时按应用既有规则保存为未绑定记录。金额是用户自行记录的节省，不是实际存款或账户余额。

## 实现

- 用 Android `AppWidgetProvider` 和 `RemoteViews` 展示卡片与按钮键盘。不新增运行依赖或数据库迁移。初始布局为 4 × 4 格，最小 250 × 300dp；桌面的网格与留白会影响实际大小。
- `HomeWidgetBridge` 在应用数据变化后发布控制器的一致快照。语言跟随已有的应用偏好。返回应用时重新读取快照。Android 也会请求周期刷新，但操作系统限制可能延迟执行。
- 应用控制器存在时，小组件使用同一个控制器；否则用短时、无界面的 Flutter 引擎运行 `widgetMain`，复用 `HomeWidgetService`、`RecordsController` 与现有 SQLite 仓储。点击数字和保存都不启动 Activity。
- 金额保持整数分，沿用既有校验和上限。原生草稿在提交前持久化金额、目标心愿、请求标识和发生日期。保存结果未确认时，提交内容保持不变，重试沿用同一请求。仓储的唯一 client token 防止重复记录；恢复时先读取已提交的快照，再允许后续写入。
- 录入期间当前心愿变化，保存时先要求核对新心愿，再提交。保存确认成功后回到卡片。这些保护不改变应用的心愿选择或成长规则。
- 每个小组件各自保存草稿。移除小组件只丢弃草稿，不删除已保存的记录。原生位图根据显示密度适配，限制为 512 × 512 像素。

## 验证

实现检查：Dart 格式、`flutter analyze`、149 项应用层／数据层／领域层／心愿绑定／语言专项测试及 arm64 release APK 编译通过。新增 8 项服务测试覆盖幂等、心愿变化、未绑定录入、存储失败、提交后恢复、重启、并发操作及无效输入。

连接的 CGL-W00 上原生验收通过：独立 `.widgetuitest` 测试包输出 `OK (1 test)`，耗时 27.428 秒。`AppWidgetHost` 测试通过真实 `RemoteViews` PendingIntent 操作按钮，核对 SQLite 记录数量及金额的精确变化，验证心愿变化提示、取消和英文，并确认后台录入不启动 Activity。应用打开时也能保存；空闲后台引擎退出后，前台控制器仍可读取。测试重跑保留独立包的已有记录，以差值断言。日常数据库不在此包内。

原始显示：2032 × 3048、密度 400、字号比例 1.0。手机验证使用 1080 × 2400、密度 480，原生宿主按 360 × 340dp 截图。原始分辨率和密度已恢复并核对，字号比例未改动。临时小组件绑定权限已撤销，测试小组件 ID 已移除。

[卡片](screenshots/widget-native-card.png)、[金额录入](screenshots/widget-native-entry.png)及[英文录入](screenshots/widget-native-en-entry.png)是设备渲染的原生宿主截图。PS5 卡片使用虚构预览数据，不是用户记录或厂商桌面的截图。具体桌面中的放置、缩放和大字号表现尚未单独验收。用户通过桌面的小组件选择器添加 Wallehog。

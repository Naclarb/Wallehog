# Android 桌面 Widget

[English](HOME_WIDGET.md) · [简体中文](HOME_WIDGET.zh-CN.md)

**Wallehog** Widget 跟随当前心愿，默认占用 **2 × 2 个桌面格子**。格子尺寸与刷新时机因启动器而异。在桌面的组件列表中添加。已有实例可能保留旧尺寸，必要时移除后重新添加。

直接在 Widget 中 **+ → 输入数字金额 → 保存**。点标题或插图打开应用。心愿创建、编辑和切换在应用内完成；没有心愿时记录不绑定。Widget 不提供算式计算器、备注日期编辑或心愿选择器。

多个 Widget 各自保存草稿。未确认的提交会锁定，重试复用请求标识以防重复记账。当前心愿发生变化时，需先核对新心愿再确认。移除 Widget 不删除已保存记录。语言跟随应用设置。

原生 Android `AppWidgetProvider` / `RemoteViews` 复用应用的 Dart 控制器和 SQLite 仓储，必要时启动短时 Flutter 后台引擎。图片按桌面尺寸与显示密度生成，限制为 1024px 并遵守视口位图内存预算。提交中移除点击动作，避免部分启动器不兼容反射调用 `setEnabled`。

回归覆盖数字录入、重试幂等、心愿变化、取消、英文、前台与后台共存、图片尺寸和跨应用加载。原生验收使用独立测试包及虚构数据。最新结果见 [STATUS](STATUS.zh-CN.md)，含设备标识的证据仅保留本地。尚未逐一验证所有启动器。

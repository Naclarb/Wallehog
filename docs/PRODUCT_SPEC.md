## 核心验收

打开应用 → 点击圆形加号 → 输入 `2` → 确认 → 保存 +¥2.00 → 关闭计算器 → 累计金额与当前 Goal 同步刷新，并提供轻微正反馈。

普通记录无需分类、预算、实际消费、备注或日期表单。未设置心愿也能快速记录，首页始终有 Goal 卡片和创建入口，不伪造目标。

## 验收用例

- `27` → 2700 分；`30-12-10-5` → 300 分；`2+3*4` → 1400 分。
- `0`、`-1`、`1/0`、非法字符、未闭合括号：保存按钮禁用。
- 已有记录 10 元 → 新建目标 100 元 → 目标 0；新增 2 元 → 总额 12 元，目标 2 元。
- 将该旧记录改为 30 元 → 总额 32 元，目标仍 2 元；将新增记录改为 3 元 → 目标 3 元；删除它 → 目标 0。
- 当前目标改名/改金额：进度起点不变；清除后创建另一个目标：进度为 0。
- 保存失败：表达式仍在，可重试，不重复新增；重启后记录、目标和汇总一致。

仍不做：账号、联网、银行/支付、广告、遥测、社交、消费羞辱、连续打卡惩罚、完整支出流水。备份导出及成长系统另列里程碑。

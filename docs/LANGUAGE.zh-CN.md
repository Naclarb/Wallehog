# 界面语言

[English](LANGUAGE.md) · [简体中文](LANGUAGE.zh-CN.md)

帮助 → 语言提供**简体中文**和 **English**，默认简体中文。修改成功后立即生效，停留帮助页，刷新 Widget，并在重启后保留。偏好写入失败时保留原语言，可以重试。

英文翻译内置文字和无障碍标签，不修改用户备注或心愿名称。首页记录金额在英文下为绿色，中文下为红色。金额符号随语言显示 `$` / `¥`，不进行汇率换算或修改数值；存储仍为人民币整数分。

`LanguageController` 在 Android SharedPreferences 中保存 `en` 或 `zh_CN`，`AppStrings` 负责展示。语言属于设备偏好，不包含在记录备份中。不需要新依赖或数据库迁移。回归覆盖双向切换、持久化及失败、金额、录入、备份、窄屏、大字体和平板。最新结果见 [STATUS](STATUS.zh-CN.md)。

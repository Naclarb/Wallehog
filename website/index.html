你可能还想知道

记录的金额，是实际存款吗？

不是。这是你自行记录的节省金额，不代表银行余额、真实入账或可支配资金。心愿进度是一种鼓励，也不表示你已经能负担某次购买。

iPhone 或浏览器可以使用吗？

当前发布的是 Android 应用。这是产品介绍与下载网站，不是网页版应用；目前没有 iOS 或网页版本。

换手机以后，记录怎么办？

先在旧设备的帮助页面导出 JSON 备份，妥善保存并核验，再在新设备导入。没有账号与自动同步，清除应用数据或卸载前请先备份。

怎样安装？应该选哪个包？

点击下方按钮，从 GitHub Releases 下载 APK 后按 Android 系统提示安装。大多数较新的 Android 手机可选 ARM64（23.02 MiB）；不确定架构或需要 ARM/x86_64 时可选通用版（57.00 MiB）。两个包功能相同。

这个网站会收集我的记账数据吗？

网站不提供记录录入，也没有添加统计脚本、广告、Cookie 或第三方字体请求。网站由 GitHub Pages 托管，GitHub 会为安全目的记录访问者 IP；应用内的记录不会因此上传到网站。

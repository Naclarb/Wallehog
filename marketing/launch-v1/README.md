## 创意

**把省下的小小一笔，变成喜欢的生活。**

32 秒、9:16 竖屏、中文无旁白。用情绪开场，用真实产品界面解释，最后以陪伴与自主节奏收尾。适用于短视频、社交动态及项目介绍。目标是先让观众记住产品的感受，再看懂核心操作，不堆叠设置和技术功能。

## 制作与检查

当前可用 skills 没有专门的视频剪辑能力。本轮使用 Pillow 排版、NumPy 合成音乐及 FFmpeg 剪辑编码，没有额外引入应用运行依赖。文字与镜头在 720 × 1280 工作画布渲染后高质量放大至 1080 × 1920，不称为原生 1080p 素材拍摄。

重做：Python 安装 `Pillow numpy imageio-ffmpeg` 后，在 Windows 上运行 `python marketing/launch-v1/render.py`。脚本使用 Windows 微软雅黑；跨平台需要替换字体路径。每次重做会覆盖本目录的生成结果，修订前请复制为下一版；用户否决的整轮工程必须保留。

审片重点：情绪是否符合品牌、文案能否一遍读懂、截图是否足够清晰。确认后再制作渠道版与实际下载引导；本轮没有代为发布、上传或投放。
